SÍTIO GESTÃO — RAFAEL CORREA

Instaladores gerados:

1. Windows x64:
   Sitio-Gestao-Rafael-Correa-1.0.0-win-x64.exe
   Execute o arquivo no Windows e siga as instruções do instalador.

2. Linux Debian/Ubuntu x64:
   Sitio-Gestao-Rafael-Correa-1.0.0-linux-amd64.deb
   Instale com: sudo apt install ./Sitio-Gestao-Rafael-Correa-1.0.0-linux-amd64.deb

O aplicativo abre o painel financeiro e de inventário com o nome de Rafael Correa.
O acesso ao clima e às cotações depende de conexão com a internet.
